# 《明末：渊虚之羽》全结局与真结局攻略

> ⚠️ **剧透警告：** 本文会提到结局名称、Boss 与后期地点。

《明末：渊虚之羽》共有 **4 个结局**。其中两个很容易错过，而且社区对“哪个才算真结局”并没有完全统一的说法。本文给出每个结局的准确条件、不可逆节点，以及一周目看完全部结局的存档备份方案。

## 速览

| 结局 | 类型 | 关键条件 |
| :--- | :--- | :--- |
| **僰人继承者（Successor of the Bo）** | 隐藏 / 提前结束 | 完成红衣女支线，在丹青苑拒绝说书人 |
| **饲药之人（Jarful of Medicine）** | 坏结局 / 默认 | 把**莹羽凿子**交给玄阳子，最后选择“再入轮回” |
| **如真似梦（Dream's Sweet Deceit）** | 隐藏梦结局（部分攻略称真结局） | 集齐**五把凿子**、完成双环、合成**轮回之环·重生**，选择“进入幻梦之境” |
| **命里无时（Bound by Fate's Threads）** | 好结局/叙事真结局（部分攻略称真结局） | 不交凿子、完成方瑶与何有哉支线并保证二人生存，最终选择时**背包里不能有重生环**，选择“进入真实之境” |

## 五把凿子（重要）

想走「如真似梦」，需要集齐 **五把凿子**。注意：**莹羽凿子不能交给玄阳子**，否则会缺一把。

| 凿子 | 获取 | 效果 |
| :--- | :--- | :--- |
| 初始凿子 | 开局自带 | 死亡后回到最近入梦点并强化 |
| **莹羽凿子** | 第二章 Boss **完美新娘·方灵** | 神龛开启“先神之言” |
| **金羽凿子** | 第三章 Boss **大西王·张献忠** | 羽露瓶回复量提升至最大 |
| **赤羽凿子** | 第四章 Boss **真龙天子·朱由检** | 武器熟练度可强化至 +10 |
| **青羽凿子** | 第五章隐藏 Boss **赵云**（真武山·鸟人居所·衣冠冢） | 解锁最后一个淬羽槽 |

> 青羽凿子需要先推进赵云支线对话；击败朱由检后回真武山鸟人居所，在衣冠冢触发赵云。

## 1. 僰人继承者（隐藏结局）

这是最早能触发、也最容易错过的结局。

1. 第三章，在 **鸟人居所（Avian Dwelling）** 遇到 **红衣女（Bo Magus / 僰人巫祝）**，**同意**她的提议。
2. 第四章，击败 **真武山** 的 **猛虎（Fierce Tiger）** 后抵达 **丹青苑**。
3. 当 **说书人** 问你是否继续前进时，**拒绝**。不要选“继续前进”。
4. 击败 **红衣女（僰人巫祝）**。

游戏会提前结束，并跳过僰人都。该结局有独立奖杯 **「僰人继承者」**。

> **不可逆节点：** 丹青苑的说书人对话。在答应继续之前，先完成真武山、Worship's Rise 的探索与 NPC 支线。

## 2. 饲药之人（坏结局 / 默认结局）

如果没有完成轮回环支线，通常会走到这里。

1. 第四章，在 **普元寺** 前往 **燃灯洞** 的路上遇到 **玄阳子**。
2. 他索要 **莹羽凿子（Jade Feather Chisel）** 时，交给他。
3. 不要完成 **何有哉** 与 **方瑶** 的支线，这样无法合成重生环。
4. 击败最终 Boss。
5. 在真实之门选择 **“再入轮回”**。

多数攻略把此结局称为“坏结局”，奖杯名为 **「饲药之人」**。

## 3. 如真似梦（隐藏梦结局）

这是条件最复杂的结局，也是日文攻略常说的**真结局**（日文奖杯名「まるで夢のよう」）。

1. **集齐五把凿子**（见上表）。
2. **保留莹羽凿子。** 玄阳子索要时选择 **“沉默”**，不要交给他。
3. 完成 **何有哉** 与 **方瑶** 的支线，并保证**二人生存**。
   - 方瑶支线需要 **秽柳滩（Hillswatch）** 的 **蜀锦围巾（Shu Silk Scarf）**，并在 **云顶城（Cloudspire）** 她家门口击败一只怪物。
4. 获得 **轮回之环·因** 与 **轮回之环·果**（第四章普元寺）。
5. 在 **僰人古都·古都深处** 的第三个谜题门，故意选择“错误”答案 **“再入轮回”**，而不是“大梦已寤”。
6. 在 **蜀神居所** 击败 **执念·心魔（Demon of Obsession）**。
7. 在 **蜀神居所** 的祭坛把因、果两环合成 **轮回之环·重生**。
8. 背包里带着重生环，击败最终 Boss **玄阳子**。
9. 在门前选择 **“进入幻梦之境”**，会看到姐妹上船的演出。

奖杯名为 **「如真似梦」**（日文：まるで夢のよう）。

## 4. 命里无时（好结局 / 叙事真结局）

GameSpot 等英文攻略把此结局称为**真结局**（「命裏無時」）。

1. 按“如真似梦”的步骤，一直做到最终 Boss 前。**4 把或 5 把凿子都可以**，青羽凿子不是必需。
2. 确保 **方瑶与何有哉存活**。
3. 在触碰门之前，确保 **背包里没有轮回之环·重生**。可以在物品栏使用/消耗掉，或干脆不合成本。
4. 击败 **玄阳子**。
5. 在门前选择 **“进入真实之境”**。左臂羽毛消失，象征摆脱须羽。

奖杯名为 **「命里无时」**。

## 哪个才是真结局？

**官方没有定义“真结局”**，四个结局都有独立奖杯。目前有两种说法：

- **GameSpot 等：** **命里无时**是真结局，因为走“真实之境”、羽毛消失，叙事上更接近真相。
- **TheGamer、DualShockers、PowerPyx、日文与部分中文攻略：** **如真似梦**是真结局，因为解锁条件最苛刻（五凿子+双环+重生环+执念心魔）。

也就是说，“按叙事真相”和“按解锁难度”会得出不同答案。英文名 *Dream's Sweet Deceit* 直译是“甜蜜的欺骗”，也暗示这仍是梦中的结局。

## 一周目看完全部结局

标准做法是手动备份存档：

1. **丹青苑说书人对话前**——用于隐藏结局。
2. **燃灯洞玄阳子对话前**——用于莹羽凿子选择。
3. **最终 Boss 后、触碰门前**——用于幻梦/真实之分。

PC 存档目录：

`C:\Users\[用户名]\AppData\Local\Project_Plague\Saved`

在每个分支前备份整个文件夹，之后还原即可重看最终选择。主机端可使用云存档/手动存档功能。

## 常见问题

**一周目能看完全部四个结局吗？**
可以，但需要手动备份存档。如果不备份，至少需要两周目，因为莹羽凿子与重生环的选择不可逆。

**把莹羽凿子交给玄阳子会锁死好结局吗？**
会。交出莹羽凿子会走向**饲药之人**结局。想走好结局，请选择“沉默”保留莹羽凿子。

**如真似梦和命里无时，哪个才是真结局？**
取决于你看的攻略。GameSpot 等把**命里无时**称为真结局；TheGamer、DualShockers、PowerPyx 与日文攻略常把**如真似梦**称为真结局。两者都有独立奖杯，都是有效结局。

**需要买 DLC 才能看结局吗？**
不需要。四个结局都在本体中。
