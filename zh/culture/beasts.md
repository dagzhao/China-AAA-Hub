# 山海异兽：为什么中国的怪物是"考据"出来的

玩西方奇幻游戏，你常常能说出每只怪物背后的设计会议：这只是龙的变体，那只是加了反转的僵尸，Boss 做成蜘蛛是因为蜘蛛在那个尺寸上读起来好看。

玩中国的游戏，感觉不一样。那些 Boss 给人的感觉是**被引用**的。

为什么有的怪物只有一个脑袋、根本没有身体？

为什么这套文化里最有名的神兽之一，只在"治国治得好"的时候才出现？

还有，为什么设定集里反复引用一本两千多年前就已经很古老的书？

这一页分三层。**第一层**是你在屏幕上真正看到的东西。**第二层**把它们连成一套能跑的模型。**第三层**交代这套模型从哪来。每个话题下面都有折叠面板——想深读哪块，自己展开。

## 第二层 · 把它们连起来

### 1. 山海经是地理志，不是神话集

关于《山海经》，最有用的一个认知是：**它是哪种书**。

它不是经，也不是史诗。它是一本**地理志**——一份对想象中世界的普查，一个区域一个区域地走，记下那里有什么、长什么样、吃什么、吃了它会怎样。其中一部分是可以辨认的真实动物。另一部分是一座长着两个脑袋的山。

这个体裁，就是中国怪物设计让人感觉像"考据"的原因。当一位设计师需要一个怪物时，他不是在情绪板上发明一个，他是在**一本普查报告里查一个**——而那本报告有序，有不同版本的异文，还有两千年来的人争论某一条到底是什么意思。

::: details 展开：「地理志」暗示了什么是「神话集」没有的

神话集解释起源和神。地理志**分配位置**。

这就是为什么东方的异兽都带地址。九尾狐在东方。饕餮在青铜器上。麒麟出现在治世。每一只怪物都在某处，也就意味着每一只怪物都可以被**找到**——而这正是一个开放世界游戏需要的东西。
:::

::: details 展开：这个说法从哪来的

《山海经》是分层写成的：较早的山经为内核，在战国期间扩充，汉代定型，最终十八卷。

它当时不是被当作虚构来读的，而是被当作**工具书**——所以它一直被注、被校、被争论，而不是被转述。
:::

### 2. 中国的怪物是修出来的，不是生出来的

这是中式怪物志和西式怪物志最大的一个差别，而它决定了一只怪物在故事里可以是什么。

西方的怪物通常有"本性"。恶魔就是恶魔，它做它这一类该做的事。中国的「妖」是一个**结果**。任何动物、草木、甚至器物，只要修炼得够久——往往是在山里待了几百年——都可能修出灵智和形态。

也就是说，妖没有先天立场。它是什么样，取决于它怎么修，以及人对它做了什么。

::: details 展开：这就是为什么中国的反派有前史

如果一只怪物的本性是固定的，那它的前史只是装饰。如果它的本性是**一个过程的结果**，那前史就是机制本身。

这就是为什么中国游戏里的反派常常被花很长篇幅、很同情地处理：设计师不是在软化一只邪恶生物，他是在**把那段修炼给你看**——它是怎么走到这一步的、从什么变的、因为谁。
:::

::: details 展开：这个说法从哪来的

「修行可以改变本类」这个观念，来自道家传统，也不少于来自佛家——见[道教密码](/zh/culture/taoism)里关于内丹的部分。

它最有影响力的文学形态是《聊斋志异》（18 世纪）：里面的狐不是怪物，是角色——骄傲、小气、慷慨、记仇，而且道德上完全可读。那本书的整个论点就是：**妖的伦理是挣来的。**
:::

### 3. 神兽的功能是征兆，不是战力

西方的龙是一种力量幻想。它的功能是当一个障碍，然后当一份奖励。

麒麟不干这个。麒麟**在天下太平时出现**。它刻意不伤害任何东西——传说它走路不踩活草。它不强大，它**有意义**。

这是一份完全不同的岗位说明，也解释了让西方玩家困惑的一件事：为什么这么多东方神兽根本不参战。它们不是用来打的，它们是用来当**信号**的——世界在告诉你它现在处于什么状态。

::: details 展开：为什么征兆比数值更适合做世界观

一个能表示世界状态的生物，可以被放在任何地方、任何尺度上，而且不需要挂一场战斗。

在村子里放一只麒麟，你就告诉玩家这个地区是太平的——成本极低，不用一句台词，也不用一个任务标记。在门上刻一张饕餮，你就告诉了他们门里的人怕什么。这是极高的信息成本比。
:::

::: details 展开：这个说法从哪来的

征兆的传统同时贯穿《尚书》和历代奏报制度：异兽、异象、天象之所以被记录，是因为它们会被**解读**——当作关于治理质量的报告。

麒麟最著名的出场是"西狩获麟"：鲁哀公十四年猎获麒麟，孔子为此绝笔，《春秋》至此而止。同一只兽，在不同的场合承担完全相反的职能，取决于当时需要说什么。
:::

### 4. 图鉴本身可以是一个角色

白泽知道天下所有精怪的真名、形貌和克制之法。

注意这是什么：**"索引"被拟人化了**。白泽不是战力，白泽是一个长了脸的资料库，而且有一本书以它命名——《白泽图》，一本教人怎么辨认和处置精怪的手册。

有画里钟馗骑着它。一位法官，带着一本索引。

::: details 展开：为什么"把图鉴做成角色"是一步真正的设计棋

一旦索引是个角色，你就可以把它放进场景里。

这些游戏正是这么用那个"会说话的引导者"的：一只替你给东西命名的生物，这既是玩法上的便利，也是一个非常古老的文学装置。图鉴不是虚构之外的一个菜单，它**在**虚构之内，而且它有看法。
:::

::: details 展开：这个说法从哪来的

《白泽图》在中古时期是作为实用的精怪手册流通的——一份"有什么、怎么办"的清单。

这和催生《山海经》的是同一种本能：一个面对不可知世界的文化，它的反应是**给它写一份清单**。
:::

### 5. 设计师在引用，不在发明

把前四条摆在一起，你就得到了中国怪物设计那种独特的质地。

怪物来自一本带地址的普查报告。它们的本性是挣来的，不是分配的。它们的非战斗成员是征兆，不是障碍。而且这套文化已经有了一个被神话化的索引。

所以当一款游戏把 Boss 摆到你面前时，那个设计动作通常是**翻译，不是发明**：哪一条、哪个版本、哪个细节是大家一直在争的——以及它动起来长什么样。

---

### 题眼

**在山海经的世界里，怪物不是敌人，它们是这个世界的一部分。你打它，是因为它挡了路，不是因为它邪恶。**

这就是为什么这么多中式怪物设计带着一种洗不掉的**出处感**。那不是风格选择。那是原材料本身的体裁，被原样带过了两千年，带进了一个恰好需要这种书的媒介。

## 第三层 · 这些东西从哪来的

| 概念 | 关键文本 | 年代 | 它贡献了什么 |
| :--- | :--- | :--- | :--- |
| 对想象世界的普查 | 《山海经》 | 战国—汉 | 带地址的共用怪物手册 |
| 第一次系统作注 | 郭璞《山海经注》 | 东晋 | 这些怪物第一次被解释，而不是被转述 |
| 给万物定名分类 | 《尔雅》 | 战国—汉 | "把名字弄对"的传统 |
| 怎么处置一个精怪 | 《白泽图》 | 中古 | 索引作为一件可用的东西 |
| 有伦理的兽 | 《聊斋志异》 | 清 | 妖作为道德角色，而非怪物 |

这一层是这个站和百科的分界线。我们不打算把《山海经》讲完——它有三百多条，而人们已经为它们争论了两千年。

我们只想让你知道一件事：你在游戏里遇到的每一条"设定"，背后都有一份真实的文本，有年代、有作者、有争论。设计师不是编的，是读来的。
