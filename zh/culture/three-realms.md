# 三界观：天庭、人间，和下面那个办公室

钟馗是「冥界最高法官」。那为什么游戏里的他要亲自提着剑满世界抓鬼，而不是坐在案台后面审案子？

为什么游戏里的死后世界会有文书流程——有桥要过、有案子要审、有队要排？

还有一个活了上万年的神，为什么会被**贬职**？

这些都不是设计师编的。它们来自一个很具体的、很古老的关于"宇宙怎么运转"的想法。

这一页分三层。**第一层**是你在屏幕上真正看到的东西。**第二层**把它们连成一套能跑的模型。**第三层**交代这套模型从哪来。每个话题下面都有折叠面板——想深读哪块，自己展开。

## 第二层 · 把它们连起来

### 1. 三界不是三个世界，是三层辖区

上有天庭，中有人间，下有地府。很容易把它理解成三个画风不同的地图。

不是。三界是**三层叠在一起的管辖区，法度各不同，而且彼此之间往来不断**。东西会往上走（祈愿、奏报、被提拔的凡人），也会往下走（敕令、被贬的神、罪犯）。东方神话里几乎每一个故事，都是从"某个东西越了它不该越的那条界"开始的。

这就是为什么"世界失了平衡"在这类游戏里是这么常见的前提。失衡不是玄学，是**行政问题**。

::: details 展开：为什么人间才是最有意思的那一层

如果天庭代表秩序、地府代表审判，那人间就是**被两边同时伸手、又谁都没完全拿下的中间地带**。

玩家恰好也活在这一层，这不是巧合。游戏需要一个"规则可以被打破"的空间。天庭和地府，都是规则已经运转良好的地方。
:::

::: details 展开：这个说法从哪来的

中国早期信仰把死者归到**泰山**之下，由一位叫「泰山府君」的神管辖。汉代的镇墓文里已经出现了冥界的官僚系统——有名册，有官吏。

佛教带着自己的一整套宇宙观进来——地狱、轮回、阎罗——但它并没有替换掉本土系统，两者是**合并**的。最后的结果是一个混血产物：一位印度法官，坐在一间中国衙门里办公。
:::

### 2. 天庭是政府，不是天堂

这是理解东方宇宙观最有用的一个点，也是西方玩家最容易搞错的一个点。

天庭有部门、有监察、有品级、有俸禄、有繁琐的礼数。它的神仙**有职位**。他们会被罚俸、被贬职、被流放、被调岗。他们有上级，他们要写文书。

它最狠的特征是：**刻意无趣**。秩序不是天庭的副产品，秩序就是天庭存在的目的。

::: details 展开：为什么"无趣"是它的设计目标

西方的天堂往往被描绘成"圆满"——挣扎的终结。而东方的天庭被描绘成一个**正在运转的机构**，那它就必然带有一个机构的所有毛病：山头、偏私、腐败、摸鱼。

这正是孙悟空的故事能成立的原因。他反抗的不是"善"，他反抗的是**人事**。他的罪状是拒绝接受一个他看不上的官职。这个笑点能响，是因为读者认得那间办公室。
:::

::: details 展开：这个说法从哪来的

《西游记》（16 世纪）定型了玉帝朝廷在民间想象中的样子——有管天马的官署、有带园丁的蟠桃园、有失职就被调岗的神仙。

但那种"官僚直觉"要古老得多。帝制中国靠科举和任命运转，而它的宇宙观，正是用建造文官系统的那套想象力建起来的。
:::

### 3. 地府的恐怖不在黑暗，在准确

走进游戏里的地府，你预期的是阴森：火、惨叫、受苦。

中国的地府在另一个频道上让人不安。它安静、程序化，而且——最要命的——**公正**。有一本账。账没错。关于你的那份档案是准确的，包括那些你早就说服自己"不算数"的部分。

这就是为什么「判官」这个角色这么有魅力，也是钟馗能活一千年不倒的原因。这个故事提供的幻想不是权力，是**一个真会认真读文件的法庭**。

::: details 展开：为什么文书比怪物更可怕

怪物可以打。一个拿着正确档案的文吏，打不了。

这是大量中国志怪小说底下的引擎：恐怖的不是体制残暴，而是体制**是对的**，而你毫无辩驳余地。主角唯一的出路，是比那份记录更诚实——或者，找出记录里的那处错误。
:::

::: details 展开：这个说法从哪来的

《太平广记》（10 世纪）是宋代编的唐代志怪总集，里面塞满了冥界审判的故事：一个普通人死了，被带到公堂上，被出示自己的名册，然后发现了一个自己早就忘了的细节。

《聊斋志异》（18 世纪）后来把这件事的地方版变成了一整个门类——城隍和判官，处理那些微小而人的案子。
:::

### 4. 死亡是一道流程，不是一堵墙

在西方框架里，死是故事的终点，或者另一个故事的起点。在东方的框架里，死是**一个过程里的一个步骤**——有阶段、有卡口、有经办人。

有一座桥。有一支队。有一个文吏。出口处还有一碗汤。

这对游戏设计有一个很容易被忽略的直接后果：**在一个"死是流程"的世界里，死者是可以被帮助、被打点、被申诉、被救回来的。** 死亡从"失败状态"变成了"一个可以去冒险的地点"。

::: details 展开：这就是为什么中国游戏敢写死角色，还能接着讲

如果死是一堵墙，写死主角就是完结。

如果死是一道流程，写死主角只是**把故事挪了个地方**。主角可以和地府谈判、可以越狱、可以被送回来、可以发现流程本身出了错。叙事是穿过那道界继续走的，不是停在界前。

这也是为什么这类故事里的"复活"很少让人觉得是开挂。它从来就不是被禁止的——它只是很贵。
:::

::: details 展开：这个说法从哪来的

十殿阎王的系统化，从唐延续到宋，在《佛说十王经》一类文本里被铺排出来。

每一殿负责一个审理阶段，各有各的主审官和刑罚。这是一套**画成建筑的法院系统**——也是为什么这些游戏里的地府，往往看起来像一片恰好建在地下的办公园区。
:::

### 5. 越界，是几乎所有故事的引擎

把前四条摆在一起，规律就出来了。

东方神话很少从"英雄想要力量"或者"反派想要毁灭"里生成情节。它从**一条界被越过**里生成情节：凡人偷了仙丹、和尚的徒弟偷了蟠桃、一个鬼逃出了名册、一个神被调去了他不接受的岗位、一个妖修过了它该有的位分。

三界存在的意义就是稳定。故事存在的意义就是它被弄得不稳定了。所以结局几乎从来不是"杀掉坏人"，而是<strong>"把世界恢复到能运转的状态"</strong>。

---

### 题眼

**东方的神话不是关于神有多强，是关于秩序如何运转——以及当它坏掉时，谁来修。**

这就是为什么在这些故事里，钟馗、判官和城隍，比天庭里最能打的那位重要。他们不是力量最大的，他们是**维护系统的人**。

也是为什么钟馗要亲自抓鬼，而不是坐在案台后审鬼：案台那边运转正常。是别的地方出了岔子。

## 第三层 · 这些东西从哪来的

| 概念 | 关键文本 | 年代 | 它贡献了什么 |
| :--- | :--- | :--- | :--- |
| 魂归泰山 | 汉代镇墓文；泰山府君信仰 | 汉 | "冥界有治理"的本土观念 |
| 地狱与轮回 | 佛教译经；《佛说十王经》 | 唐—宋 | 阎罗与十殿 |
| 冥界审判的文学化 | 《太平广记》 | 宋（收唐传奇） | 名册、公堂、被遗忘的细节 |
| 天庭作为办公室 | 《西游记》 | 明 | 品级、升迁、贬黜、偷蟠桃 |
| 地方神办小案子 | 《聊斋志异》 | 清 | 城隍与判官的人间案卷 |

这一层是这个站和百科的分界线。我们不打算把中国宇宙观讲完——它内部并不自洽，而不自洽恰恰是有意思的地方。

我们只想让你知道一件事：你在游戏里遇到的每一条"设定"，背后都有一份真实的文本，有年代、有作者、有争论。设计师不是编的，是读来的。
