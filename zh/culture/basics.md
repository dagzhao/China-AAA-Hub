# 文化 101：玩家入门手册

被满天的葫芦弄糊涂了？不理解为什么每个人都在谈"天命"？你来对地方了。要玩透中国 3A 大作，你需要**东方的叙事逻辑**——而它恰好是可以教的。

### 🎓 每个模块怎么读

四个模块。每一篇都是三层结构：

1. **你在屏幕上看到的** —— 一张符号速查表，每一条直链到词典对应词条。
2. **它们怎么连起来** —— 底下的那套逻辑，折在面板后面，想展开就展开，不想就跳过。
3. **这些东西从哪来** —— 真实文本，带年代、作者和争论。

| 模块 | 主题 | 为什么重要 |
| :--- | :--- | :--- |
| **01** | **[道教密码](./taoism)** | 炼丹、符咒，以及支撑所有战斗设计的"气"。 |
| **02** | **[三界观](./three-realms)** | 天界、凡间与地府——钟馗的职能范围。 |
| **03** | **[轮回与因果](./karma)** | 为什么在东方故事里，死亡从来不是终点。 |
| **04** | **[山海异兽](./beasts)** | 从《山海经》到次世代游戏中的 Boss 设计。 |
