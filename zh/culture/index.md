# 文化 101

中国 3A 游戏不只是借用神话——它们靠神话运转。想读懂**东方的逻辑**，把这四个模块过一遍。

每个模块都是同一套结构：**你在屏幕上看到的**、**它们怎么连起来**、**这些东西从哪来**。深的内容折在面板后面，一个模块你可以两分钟扫完，也可以读二十分钟。

### 🎓 模块

| 模块 | 主题 | 为什么重要 |
| :--- | :--- | :--- |
| **01** | **[道教密码](./taoism)** | 阴阳、五行、气、符箓——为什么这些游戏里的战斗是形而上学。 |
| **02** | **[三界观](./three-realms)** | 天庭、人间、地府是三层辖区——为什么这套宇宙观是一张组织结构图。 |
| **03** | **[轮回与因果](./karma)** | 死是检查点，账本自己会平——为什么没有人能"赢了就一笔勾销"。 |
| **04** | **[山海异兽](./beasts)** | 所有 Boss 背后共用的那本图鉴，以及为什么中国的怪物是"考据"出来的。 |
