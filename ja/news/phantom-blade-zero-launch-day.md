# 『影之刃零』発売初日：Steamピーク72万、好評価率83%

<p><em>2026年10月30日 · 影之刃零 · 約8分</em></p>

## 初日同時接続：ピーク約72万、Steam歴代15位

解禁から **20分** 足らずで同時接続は **10万** を突破し、Steam世界売上ランキング首位に。その後も伸び続け、約 **13時間** で初日のピークに到達しました。

| 時間（北京時間） | Steam 同時接続 |
| :--- | :--- |
| 10:20頃（解禁約20分後） | 10万突破、世界売上ランキング首位 |
| 13:30 | 431,541 |
| 午後 | 45万突破 |
| 20:00 | 60万突破 |
| 22:00 | 70万突破 |
| 23:00頃 | 約72万（ピーク723,876）、なお68万超が接続中 |

- **歴代同時接続ランキング15位。** 次に追うのは『Battlefield 6』の747,440、その上が13位『Baldur's Gate 3』の875,343です。初日のカーブから、週末にさらなる更新が期待されます。
- **2026年のシングルプレイ作品で最強クラスの初日。** 複数メディアは『バイオハザード9：レクイエム』（約34.4万）や『Forza Horizon 6』（約30.3万）を大きく上回ると指摘しています。
- **ただし『黒神話：悟空』には及ばず。** 悟空のSteamピークは約240万で、中国産シングルプレイの最高記録として残っています。
- 発売日が木曜日だったため、**週末のピーク**はさらに上がるとみられます。

## Steamレビュー：83%が好評、低評価はほぼ「動作」関連

ユーザーレビューは初日序盤 **76〜79%** から、夜には **83%**（約2万3,400件）まで回復し、「ほぼ好評」となりました。

- **低評価は驚くほど一致しており、内容とは無関係：** クラッシュ、シェーダーコンパイルの遅さ、ロードの長さ、フレームレートの不安定さ、NVIDIAドライバー621.01との互換性問題、AMD製GPUでの髪・空の表示不具合など。
- **好評価のキーワード：** 打撃感、武器の手感、コンボの滑らかさ、香港映画黄金期のような演出。
- メディアもプレイヤーも「**内容ではなくハードウェア適性に足を引っ張られている**」という点で一致しており、パッチ次第で評価は戻せる状況です。

## 初日パッチ5GB：レイトレ強化、ドライバーは巻き戻し推奨

初日パッチはPC版が約 **5GB**（PS5版は別途配信）。ストーリー、ゲームプレイ、バランスの変更はなく、**レイトレーシング／パストレーシング性能の大幅な向上**、バグ修正、ラスタライズ描画の最適化が中心です。

さらに異例なのがドライバーに関する公式の軌道修正です。発売前は **NVIDIA 621.01** への更新を勧めていましたが、初日には「一部シーンで性能が不安定」として、**クリーンインストールで617.42へ戻す**か、次期ドライバーの配信を待つよう案内しました。

::: tip 起動前にやっておきたい2つ
まず初日パッチをインストール。NVIDIAユーザーでドライバーが **621.01** の場合は、**617.42** をクリーンインストールしてから起動するよう公式が推奨しています。
:::

## PS5／PCの初日パフォーマンス

初日のメディア・プレイヤー報告によると：

| 環境 | 初日のパフォーマンス |
| :--- | :--- |
| PS5 · パフォーマンスモード | 多くの場面で60fps前後。雨のシーンや一部ボス戦でフレーム低下、約1秒の引っかかりとテクスチャのポップインが発生 |
| PS5 · クオリティモード | フレームレートが厳しく、優先は非推奨 |
| PS5 Pro | 最も安定。パフォーマンスモード＋レイトレーシングでもほぼ60fpsを維持 |
| PC · RTX 5060 | ネイティブ1080p＋レイトレーシングで約41〜45fps |
| PC · RTX 5090D V2 | ネイティブ4Kのパストレーシングでは60fps維持が困難。DLSS／FSRが事実上必須 |

公式の動作環境も超解像技術の使用を前提としています。5GBパッチがレビューで指摘されたフレーム時間の問題を解消できるかは、週末の追加検証が必要です。

## メディア88点、プレイヤー83%：落差の理由

メディアスコアは堅調です。MetacriticはPC版 **88**（45媒体）、PS5版 **86**（38媒体）、OpenCriticは **90** 前後。IGN本部9/10、IGN中国10/10、GameSpot 8/10で、Eurogamerの3/5が唯一の低評価です。

- **メディアが評価するのは戦闘と演出：** パリィと「殺気」、Ghost Stepの回り込み反撃、55種以上の武器の手感。
- **メディアが批判するのは物語と構造：** 先の読める復讐劇、見えない壁、リニアなレベル設計。
- **プレイヤーが低評価するのは技術面：** クラッシュ、シェーダー、ドライバー互換性。難易度が低いという声もありますが、本作はソウルライクではありません。
- 結論は明快です——**評価の回復はコンテンツではなく、パッチとドライバーにかかっています。**

## 中国ゲーム業界の「バトンタッチ」

発売当日、『黒神話：悟空』のプロデューサー**馮驥**氏が長文の祝福を投稿しました。梁其偉氏と長年の知己であり「殊途同帰（道は違えど行き着く先は同じ）」だと振り返り、「シングルプレイゲームがより高級なゲームというわけではない」、中国のシングルプレイ開発者は「より良い時代、そしてより難しい時代」にいると綴り、最後に「**桃李不言、功不唐捐**」（良い仕事は自ずと語られ、努力は決して無駄にならない）と記しました。「これからの時間は『影之刃零』に捧げる」とも。梁氏は「感謝します。ゲームを楽しんでください」と返しています。

- **10月20日**には馮驥氏が「あと9日、一日が一年のように長い」と投稿。発売前夜には梁氏の投稿に「真剣にプリロードし、目覚ましもセットした」とコメントしました。
- NetEase『帰唐』チームは真っ先に祝福アートを贈り、チーム全員に本作24本を配布。
- 『Delta Force』は『影之刃零』とのコラボを発表し、PlayStation中国の公式アカウントはヘッダーを本作に差し替えました。
- クレジットには馬暁軼、馮驥、劉偉、李松倫、吉田修平、Tim Sweeney、金亨泰らが名を連ねています。

## 予約約85万本、公式の販売数は依然未発表

- 分析会社 **Alinea Analytics** の推計では、デジタル予約は約 **85万本**、約 **4,300万ドル**。内訳はSteam **73.8%**、PS5 **26.2%**、大中華圏の購入者が約 **62.5%**。
- WeGameを含めると総販売数が **100万本** を超えたとする報道もありますが、**S-GAMEは公式の販売数を発表していません**。
- 報道によると開発費は約 **3〜4億元**。中国価格はスタンダード268元、デラックス328元、限定コレクターズ版は1,199元で2万セット。
- ゴールデンジョイスティック「アルティメット・ゲーム・オブ・ザ・イヤー」の投票は北京時間 **10月31日 07:59** まで、授賞式は **11月11日**。
