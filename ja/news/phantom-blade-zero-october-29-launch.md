# 『影之刃零』発売日・解禁時間

<p><em>2026年10月21日 · 影之刃零 · 約6分</em></p>

> 📅 **続報：** 本作は10月29日に発売されました。初日の成績は[発売初日まとめ](/ja/news/phantom-blade-zero-launch-day)へ。

『影之刃零（Phantom Blade Zero）』の発売まで、あと **8日**。当初の9月9日から50日延期され、S-GAMEの“武侠パンク”アクションRPGは **2026年10月29日** に PlayStation 5、PlayStation 5 Pro、PCで発売されます。最終プレビューの解禁は **10月8〜9日** で、評価は異例なほど一致しています。複数の媒体が「『隻狼』以来の最高のアクションゲーム」「年間最優秀ゲーム候補」と評しました。

## 発売日と解禁時間

- **2026年10月29日 02:00 UTC**（**北京時間 午前10:00**）。
- **対応機種：** PS5、PS5 Pro、Steam、Epic Games Store、WeGame、TapTap PC。
- **Xbox版は発売時点で未展開。** PS5の約12か月のコンソール独占は複数メディアが報じていますが、S-GAMEとソニーは正式発表していません。
- **中国価格：** スタンダード版 **268元**（予約特価 **258元**）、デラックス版 **328元**。
- **プリロード**は**10月27日 10:00**に開始。詳細は[発売前夜まとめ](/ja/news/phantom-blade-zero-launch-eve)。

**地域別の解禁時間：**

| 地域 | 現地時間 |
| :--- | :--- |
| 北京 / シンガポール（UTC+8） | 10月29日 10:00 |
| 東京（UTC+9） | 10月29日 11:00 |
| シドニー（UTC+11） | 10月29日 13:00 |
| ロンドン（GMT） | 10月29日 02:00 |
| 中央ヨーロッパ（CET） | 10月29日 03:00 |
| 米国太平洋（PDT） | 10月28日 19:00 |
| 米国東部（EDT） | 10月28日 22:00 |

Steamなど一部ストアでは **10月28日** と表示されることがありますが、これはUTC解禁による時差です。世界共通の解禁は **10月29日 02:00 UTC** です。

延期は **2026年6月3日** に発表されました。クリエイティブディレクターの **梁其偉（Soulframe）** は、キャラクターモデルの強化、一部シーンの再構築、レイトレーシングに頼らない画質向上に時間を使ったと説明。他の大作を避けるための延期ではないとも述べています。

## 最終プレビューの評価

**10月8〜9日**、IGN、GameSpot、Game Rant、DualShockers、Wccftechなどが4〜6時間の試遊記事を公開しました。

- **戦闘が最大の売り。** パリィと「殺気（Sha-Chi）」を軸にした攻防は『隻狼』と繰り返し比較されます。青い攻撃はガード可能、赤い攻撃は回避必須。精密な防御で **Ghost Step** が発動し、自動的に背後へ回って反撃します。
- **ボスと武器の深さ。** 各ボスが固有武器をドロップし、単一の最適解ではなく流派の多様性が評価されています。
- **懸念はパフォーマンス。** 高性能PCでもフレームレート低下を報告した記者がいる一方、4K/ウルトラで快適に動いた例も。S-GAMEは発売まで最適化を続けるとしています。
- **厳密なソウルライクではない。** 敵はリポップせず、死亡ペナルティもなく、高速コンボと映画的演出が中心です。

## ボリューム、プレイ時間、エンディング

- **8章・8つのシームレスに繋がるセミオープン箱庭マップ**。オープンワールドではありません。
- **メイン武器30種以上**＋**約25種の「影刃」サブ武器**。ボスは **50体以上** との報道。
- メインストーリー約 **25〜30時間**、サブ要素込みで約 **40時間**。周回プレイとフル再スキルに対応。
- **8エンディング**（梁其偉氏が確認）。『エルデンリング』より2つ多く、サブクエストの達成度と手がかりフラグで分岐。メインだけを進めると「バッドエンド」になります。
- **「66日間」モード：** 66回の命。1回の敗北で1つ失い、**専用セーブ**、オートセーブのみ、**プラチナトロフィー対象外**。使い切ると特別な「後悔」エンディングが発生します。

## 『影之刃零』はソウルライク？

**いいえ。** S-GAMEと最終プレビューは、本作を『ダークソウル』よりも『Devil May Cry』『Ninja Gaiden』に近い、高速でコンボ重視のアクションゲームと説明しています。

- 敵は**リポップせず**、死亡ペナルティもありません。
- 戦闘の中心は**パリィ**、**Ghost Step** のカウンター、映画的な演出で、スタミナ管理ではありません。
- **「66日間」モード**は66回の命を使う永久死亡チャレンジですが、任意で、専用セーブを使用し、**プラチナトロフィーには影響しません**。

## 予約とウィッシュリスト

**9月17日** に全プラットフォームで **300万件** を突破し、当時Steamウィッシュリスト4位。予約は **8月11日** に開始され、公式は「予想を大幅に上回る」とコメント。約 **1時間** でSteam世界売上ランキング首位、PlayStation香港の予約ランキングでも1位になりました。

## 最後の大型発表

**10月13日**、IGNがオープニングの馬車ボス **「The Hunt」** を独占公開。第2フェーズで腕が増え、4本の斧を同時に振るいます。同じ映像でデラックス版の外見 **「Blood-Steel Form」** も披露されました。純粋な外見スキンです。

## 体験版なし、DLCロードマップなし

8月にPS Storeで一時的に体験版項目が現れましたが、S-GAMEは **公開体験版を出さない** 方針を確認。**発売後のDLCロードマップも未発表** です。試遊版はイベント会場のみ。**10月20日** 時点で最終ローンチトレーラーはまだ公開されていません。

## 発売時に注目したいこと

- **初日のパフォーマンス**、特にPCとPS5 Pro。
- **レビュースコア**（10月21日時点では未解禁）。
- **12か月のコンソール独占が正式確認されるか。**
- **発売後のサポート**——DLCは未発表ですが、成功すれば拡張の可能性は高いでしょう。
