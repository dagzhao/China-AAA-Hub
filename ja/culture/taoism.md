# 道教のコード：なぜ中国の戦闘は「形而上学」なのか

『黒神話：悟空』では、体力が底をつくと**瓢箪**を取って飲みます。なぜ瓢箪なのでしょうか。
ボスが大振りを溜めたとき、ゲームは回避ではなく**迎え撃つ**ほうを評価します。なぜ退かずに受けるほうが*得*なのでしょうか。
そして、なぜ中国のゲームの属性システムは非対称なのでしょうか——火は金を熔かすのに、金は木を切る。

これらはデザイナーが考え出したものではありません。三つの答えは、同じ一つの場所から来ています。

このページは三層構造です。**第一層**は、画面で実際に見ているもの。**第二層**は、それらを一つの動く模型として繋ぎます。**第三層**は、その模型がどこから来たかを示します。各トピックの下には折りたたみパネルがあります——読みたいものだけ開いてください。

## 第二層 · それらはどう繋がるのか

### 1. 陰陽は位相であり、陣営ではない

西洋ファンタジーの底色は二項対立です。聖光と影、秩序と混沌——二つの隊が向かい合い、間に線が引かれます。

道教にその構造はありません。陰陽は二つの軍ではなく、一つの循環の二つの位相です。しかもそれぞれの半ばには、相手の種がすでに宿っています。あの記号の二つの点がそういう意味です——純粋に一方であるものは何もない。

戦闘に落とし込むと、「強くなる」の意味が変わります。「俺の数値がお前を上回る」ではなく、「お前の位相を読み、その向きを変える」になるのです。

::: details 開く：「柔よく剛を制す」は、腰を引けという意味ではない

初心者は「陰」を「譲ること」と読みます。後ろに下がり、道を空けることだと。逆です。陰は**より高度な力の使い方**です。押さないのではなく、**押し返す相手の正面に立たない**のです。

打ち込まれた力を受け取り、それが来た場所へ送り返す。

だから中国のアクションゲームでは、回避よりパリィのほうが報酬が大きいことが多い。回避は拒否です——その交換を断った。パリィは相手の攻撃を自分の資源に変換します。一方は余白、もう一方は反転です。
:::

::: details 開く：この考えの出典

『道徳経』第四十章：**「反者、道の動なり」**——物事は極まれば反対側へ転じる。これが「位相」の最も原初的な定式です。

周敦頤『太極図説』：太極が動いて陽を生じ、動きが極まれば静かになり、静から陰が生じる。陰陽は運動の二つの**状態**であり、二つの実体ではありません。
:::

### 2. 五行は関係であり、ダメージ種ではない

西洋 RPG の属性システムは対称です。火は氷に強く、氷も火に強い。二つのリストが互いを指しています。

五行は対称ではありません。**隣り合う二つの要素の間に、常に二本の矢印がある有向グラフ**です。

- **相生**：木 → 火 → 土 → 金 → 水 → 木
- **相克**：木 → 土 → 水 → 火 → 金 → 木

| 要素 | 生（誰を養う） | 克（誰を抑える） | 誰に克たれる | 典型的な戦闘の役割 |
| :--- | :--- | :--- | :--- | :--- |
| **木** | 火 | 土 | 金 | 回復、持続、制御 |
| **火** | 土 | 金 | 水 | 燃焼、爆発 |
| **土** | 金 | 水 | 木 | 防御、体幹、重量 |
| **金** | 水 | 木 | 火 | 会心、防御破壊、鋭さ |
| **水** | 木 | 火 | 土 | 凍結、身のこなし、流転 |

同じ要素が、隣には滋養であり、一つ飛ばすと抑圧です。環の上の位置がすべてを決めます。

これが同時に二つのことを説明します。中国のゲームが本当に深い五行システムを作れる理由——選んでいるのはダメージ種ではなく、**環の上の一つの席**だから。そして多くのゲームが表面だけになる理由——倍率表を書くのは安く、環を本当に作るのは安くない。
:::

::: details 開く：なぜ相生のほうがずっと作りにくいのか

相克は簡単です。倍率を一つ掛ければ終わりです。

相生は難しい。なぜなら「自分が強くなる」という出来事が、**他人の上で**起きることを要求するからです——味方、環境、召喚物。ほとんどのシステムはそれを静かに切り捨て、その結果、五行は中国風の皮をかぶった耐性表に退化します。

うまくやれば、相生はバフの伝播になります。木のキャラが火の味方を強化し、火がさらに先へ渡す。失敗すれば「同属性＝耐性」に簡略化され、それはただの耐性表が衣装を着ただけです。
:::

::: details 開く：この考えの出典

『尚書・洪範』が最古の記録です。**「五行：一に曰く水、二に曰く火、三に曰く木、四に曰く金、五に曰く土」**。書かれていないことに注意してください——名前を並べただけで、順位も、誰が誰に克つかも言っていません。

五つを相生・相克の循環に組み上げたのは、戦国から漢にかけての構築です。董仲舒『春秋繁露』はこれを完全な天人政治哲学として整えました——五行は自然を説明するだけでなく、王朝の交代をも説明します。

つまり五行は最初から「属性ダメージ」ではありませんでした。それは**関係学**です。
:::

### 3. 気は媒体であり、マナバーではない

ほぼすべてのゲームにマナバーがあります。気はマナではありません。この違いは重要です。

マナは**資源**です。物理的な意味を持たず、「あと何回呪文が撃てるか」を記録するだけです。

気は**媒体**です。呼吸であり、体力であり、勢いであり、天候でもあります。気が巡れば健やか。滞れば、あるいは違う経路へ流れれば、病になり——邪に入られます。

だから中国の設定では、西洋の設定が奇妙に思うことが平然と起きます。**体力と法力が同じ一つのものである**。この枠組みでは、本当に同じだからです。払っているのは二つの別の池ではなく、一つの媒体の二つの向きです。
:::

::: details 開く：「走火入魔」とは何か

文字どおりには「火が走り、魔が入る」。内丹修行における実際のリスク概念です——修行が狂えば、人は制御を失う。

ゲームではこう現れます。溜めすぎた攻撃が反噬する、禁術が正気度を削る、気海を割られて硬直する。これらは場当たり的な罰則ではありません。「気は経路を誤りうる」という前提から直接導かれた結果です。
:::

::: details 開く：この考えの出典

『荘子』知北遊篇：**「人の生は、気の聚なり。聚まれば則ち生、散ずれば則ち死」**——生と死は気の集散にすぎない。

『黄帝内経』は気を身体運行の基本媒体とし、漢方の「気血」概念はここから来ています。
:::

### 4. 丹とは、身体を炉にすること

初期の道教が追ったのは**外丹**でした。丹砂・鉛・水銀を炉で練り、不老不死の薬を作る。数百年続いた実験計画であり、少なからぬ修行者を殺しました——唐の皇帝数人を含みます。

やがてこの伝統は内側へ転じます。**内丹**は薬を練るのをやめ、身体そのものを炉としました。精を練り、気を練り、神を練り、最後に体内に丹を結ぶ。

この転回が一つのことを説明します。なぜ中国 RPG の成長曲線は修仙の階段に似るのか。**修仙はすでに階段だったから**です。段階、行き詰まり、突破——すべて揃っていて、テレビゲームより千年早い。

::: details 開く：なぜ「境界」がレベルにそのまま接続するのか

内丹修行は段階に分けられます——筑基、煉精化気、煉気化神、煉神還虚——各段階に公认の目印と既知の壁があります。

これをそのままゲームに移せば、成長曲線を発明する必要はありません。境界の名前、突破の条件、失敗の罰（走火入魔）はすべて既製です。修仙ものとゲーム的な言語が相互に翻訳できるのは、構造的に同じものだからです。
:::

::: details 開く：この考えの出典

『周易参同契』（後漢・魏伯陽）は「万古の丹経の王」と尊ばれ、内丹理論を初めて体系化したテキストです。

葛洪『抱朴子』内篇（四世紀頃）は外丹の処方を大量に記録しつつ、外丹から内丹への移行を示す鍵となる文献でもあります——彼は丹砂を練りながら、同時に養生を語る。この伝統が**考えを変えていく**過程が、この本で見られます。
:::

### 5. 符とは、より高い権威が発した命令である

西洋の魔法は本質的に**所有**です。魔法使いが力を持ち、呪文を放つ。

道教の符籙は**授権**です。術者はより高い天の名において命じる。術者は力を所有せず、力を**執行**します。

この違いがすべてです。マナの池は枯らせ、打ち消し、消散させられます。しかし玉皇大帝の名で発行された逮捕令状は、理論上、受け取った側に拒否の余地を残しません。

だからこそ、こうした物語で符が向かうのは「勝てない敵」ではなく「殺せない存在」です。鬼を封印し、追い払い、連れて行く。滅多に「殺し」はしない——殺すことはそもそも自分の権限の外だからです。

::: details 開く：なぜ法宝は「主を認める」のか

符・印・令は同じ前提を共有します。**権威は授与されなければならない**。伝承の外の者が描いた符は、ただの紙切れです。

この論理はそのままゲームに伸びています。伝説の武器を拾っても、「主を認める」まで、継承の試練を終えるまで、開眼するまで使えないのはなぜか。それは神秘的な飾りではありません。符籙の前提を物体に適用したものです——道具を使う資格は、**あなた個人の強さ**ではなく授権から来る。
:::

::: details 開く：この考えの出典

『道蔵』には符籙派の文献が大量に収められています。

伝統的な符の形式は極めて厳格です——起筆、符頭、符胆、符脚——そしてそれは、かなり官僚的な問いに対応しています。誰が発行するのか、何のために、どの相手を拘束し、いつ効力を持つのか。呪文というより、法的文書に近い読み味です。

伝統的に画符の前に斎戒と焚香が必要だったのも、そのためです。あなたは字を書いているのではない。**書類を発行している**のであり、発行する資格が要るのです。
:::

### このページの要旨

五つを並べると、それらはもはや五つの知識ではありません。一つの考えを、五つの角度から見たものです。

**世界には規則がある。規則は読める。そして規則を読んだ者には、力む必要がない。**

陰陽は力の向きを変えろと言い、五行は環の上の位置が絶対の力より重要だと告げ、気は養うべきものが資源ではなく媒体だと教え、丹は上達の唯一の道が自分自身の改造だと示し、符は力が蛮勇ではなく権限から来ると語ります。

「柔よく剛を制す」は綺麗事ではありません。この模型を突き詰めた結論です。

## 第三層 · これらはどこから来たのか

| 概念 | 鍵となるテキスト | 時代 | 何をもたらしたか |
| :--- | :--- | :--- | :--- |
| 反者道の動 | 『道徳経』第四十章 | 戦国 | 「位相」の原初的な定式 |
| 五行の名前 | 『尚書・洪範』 | 先秦 | 水火木金土の最古の列挙 |
| 相生相克の環 | 董仲舒『春秋繁露』 | 前漢 | 五行を一つの循環に配した |
| 内丹 | 『周易参同契』 | 後漢 | 身体＝炉鼎の理論化 |
| 外から内へ | 葛洪『抱朴子』内篇 | 東晋 | 外丹から内丹への転換の一次記録 |
| 符籙の論理 | 『道蔵』符籙派文献 | 歴代 | 符がなぜ公文書めいているのか |

この層が、このサイトと百科事典の境界線です。道教を語り切るつもりはありません——それは『道蔵』の仕事で、千巻を優に超えます。

伝えたいのはただ一つ。ゲームで出会う一つひとつの「設定」の裏には、実際のテキストがあり、年代があり、著者がいて、論争がある。デザイナーは作ったのではなく、**読んだ**のです。
