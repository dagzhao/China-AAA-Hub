# 輪廻と因果：誰も「勝って終わり」にはできない

西洋のゲームが主人公を殺せば、物語は終わります。中国のゲームが主人公を殺しても、物語は続きます——何も起こらなかったかのように続くことさえあります。

「この借りは必ず返させる」はどの言語でも定番の脅し文句です。しかし東洋の物語では、それは脅しではなく**事実の陳述**であり、しかも日程表が付いています。

少なからぬゲームで、最後のどんでん返しは「敵と主人公は同一人物で、同じ輪を別の周回で回っているだけ」だったりします。

これらは驚かせるための仕掛けではありません。西洋とは**本当に違う**因果の模型から来ています。

このページは三層構造です。**第一層**は、画面で実際に見ているもの。**第二層**は、それらを一つの動く模型として繋ぎます。**第三層**は、その模型がどこから来たかを示します。各トピックの下には折りたたみパネルがあります——読みたいものだけ開いてください。

## 第二層 · それらはどう繋がるのか

### 1. 死はチェックポイントであり、壁ではない

これが構造的な違いであり、残りすべてはここから導かれます。

西洋の物語は通常、死を境界条件として扱います。越えれば、あなたはもう物語の中にいません。東洋の物語は死を**循環の中の一工程**として扱います。あなたはそこから戻ってくる——変化し、誰かに借りを作り、あるいは誰かに貸したまま。

設計上の帰結は甚大です。死が壁なら、人物を殺すことは終止符です。死がチェックポイントなら、人物を殺すことは**場面転換**です。一ページ目で主人公を殺しても、三ページ目で同じ物語を語り続けられます。

::: details 開く：なぜ「死んでやり直し」が安っぽくならないのか

西洋の枠組みでは、復活には理由が要ります——奇跡、破られた規則、支払われた代償。常に例外として読まれます。

循環の枠組みでは、戻ることは例外ではありません。デフォルトです。面白い問いは「どう戻ったか」ではなく、**「何として戻り、まだ何を負っているか」**です。
:::

::: details 開く：この考えの出典

『阿含経』の十二因縁は、存在を一つの循環として描きます。第一原因はなく、悟り以外に出口もない——生、老、死、そしてまた。

仏教がこれを中国へ運び、土着の「統治された冥界」という観念（モジュール 02）と統合されました。これらのゲームが引く民間の宇宙観はその結果です——純粋に仏教でも、純粋に土着でもない、動いている混血です。
:::

### 2. 因果は帳簿であり、判決ではない

因果を punishment と訳すのは最も多い誤訳です。仕組みが逆になります。

因果は裁判官が下すものではありません。量刑の手続きはありません。帳簿は**自ら帳尻を合わせます**——重さが圧力を生むように、誰かがそう決めたからではなく。

判決は上訴でき、袖の下で動き、より強い権力で覆せます。帳簿は覆せません。その恐ろしさは、モジュール 02 の冥界の記録の恐ろしさと同じです。誰もあなたを迫害していない。ただ**帳簿が正しい**だけです。

::: details 開く：なぜ「悪の敵役」より強力なのか

悪の敵役には動機が要り、動機は反論しやすいものです。

借りには動機が要りません。返済している——あるいは取り立てている——人物は、同情的で、怪物的で、しかも完全に理解可能でありえます。作者が何も正当化しなくても。彼はそれを選んでいるのではなく、**決済している**のです。
:::

::: details 開く：この考えの出典

『太平広記』には「報応」の分類が丸ごとあります。多くは唐代の資料から採られ、意図的に定型的です。残酷な行いがあり、そして時には数十年後、帳尻が合う。

ここで因果は哲学から**プロットの機械**になります。遅延こそが要点であり、それによって最終的な決済が偶然ではなく運命として読まれます。
:::

### 3. なぜ請求書はすぐ来ないのか

ここが最も見落とされる部分であり、因果に対する最も一般的な反論に答える部分です。世界が帳尻を合わせるなら、なぜ悪人が栄えるのか。

この問いは四世紀の中国で答えられました。僧・慧遠の『三報論』です。

報いには三つのタイミングがあります。**現報**（この世で）、**生報**（次の世で）、**後報**（さらに後の世で）。帳簿は遅れているのではありません。ただ**あなたの予定表では動かない**だけです。

::: details 開く：なぜこれが書き手への贈り物なのか

報いが後の世に着地しうると分かれば、東洋の物語で最強の動機が解放されます。**自分が負ったのではない借り**です。

人物は祖先の行いの帰結として生まれることができ、あるいは半分しか覚えていないことを一生かけて片づけることができます。西洋にはほとんどない動機構造であり、これらのゲームの「この借りを返す」が一本の筋を支えられる理由です。
:::

::: details 開く：この考えの出典

慧遠（334–416）は『三報論』を、ある具体的な批判に答えるために書きました。仏教が約束する公正は明らかに偽りだ——悪人が栄え、善人が苦しむではないか、と。

彼の答え——会計は本物で、ただ決済期間が人の寿命より長いだけ——は中国式の標準解答となり、中国の小説の「因果」がしばしばキャンセルではなく**遅延**として読まれる理由になりました。
:::

### 4. 忘却は慈悲であり、同時に消去でもある

冥界の出口に橋があり、橋のたもとに老女がいて、手に椀を持っています。

飲めば前世が消える。あなたは綺麗に生まれ変わり、悲しみも恨みも持たない。飲まなければ、すべてを傷として次の世へ持ち越します。

これはこの文化で最も古い未解決の論争であり、しかも**関所での一つの選択**として舞台上に置かれています。忘却は親切か、それとも一つの自己の破壊か。同じ場面が、両方の読みを完全に支えます。

::: details 開く：なぜ答えより選択が重要なのか

この場面が構造的に実際にしていることに注目してください。人物に**次の世を決める一つの決定**を与えているのです。

これは異例に潔い物語工学であり、ゲームはこれを絶えず借用します。記憶のない主人公はここではクリシェではありません。**橋で選択をした人物**であり、物語はその選択を確かめる旅なのです。
:::

::: details 開く：この考えの出典

孟婆と忘川は、この宇宙観への**後発の**追加です。明清の民間冥界で定番となり、志怪や『聊齋志異』を通して定着しました。

重要なのは、それらが後から足されたという事実です。より古い冥界は死者を処理しましたが、消しはしませんでした。あのスープは物語上の発明であり、非常に良い発明です。
:::

### 5. 借りは世を越える。だから誰も「終われない」

最初の四つを並べれば、物語構造が見えてきます。

死がチェックポイントで、帳簿が自ら帳尻を合わせて上訴できず、決済が数世先まで繰り延べられ、記憶は持ち越すことも消すこともできる——ならば**どんな物語も本当には閉じません**。

この枠組みでの勝利は、借りの取り消しではありません。**借りへの一つの支払い**です。だからこれらのゲームは主人公の勝利で終わってもなお未完に感じられ、続編が後付けに見えないのです。

---

### このページの要旨

**因果のある世界では、誰も勝って終われない。あなたは払うか、誰かが代わりに払う相手になるか、どちらかです。**

これが『黒神話：悟空』と『影之刃零』の下に共通して流れるエンジンです。主人公が追っているのは勝利ではなく**決済**であり、その二つの目標の差が、西洋の復讐譚と東洋の復讐譚の差です。

## 第三層 · これらはどこから来たのか

| 概念 | 鍵となるテキスト | 時代 | 何をもたらしたか |
| :--- | :--- | :--- | :--- |
| 輪廻 | 『阿含経』十二因縁 | インド仏教 | 死は一工程であり終点ではない |
| 三報 | 慧遠『三報論』 | 東晋 | なぜ善人が苦しむか——報いは三世に分かれる |
| 報応としての筋 | 『太平広記』報応類 | 宋（唐伝奇） | 遅れて届く決済 |
| 装置としての忘却 | 孟婆と忘川 | 明清 | 次の世を決める一つの選択 |

この層が、このサイトと百科事典の境界線です。仏教哲学を語り切るつもりはありません——その経典は数千巻あり、それ自身の内部でも一致していません。

伝えたいのはただ一つ。ゲームで出会う一つひとつの「設定」の裏には、実際のテキストがあり、年代があり、著者がいて、論争がある。デザイナーは作ったのではなく、**読んだ**のです。
