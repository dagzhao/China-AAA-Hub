# 文化 101：プレイヤーガイド

飛び交う瓢箪や、「天命」という言葉の意味に迷っていませんか？ ここが正しい場所です。中国の 3A ゲームを極めるには**東洋の論理**が要ります——そしてそれは、教えられるものでした。

### 🎓 各モジュールの読み方

四つのモジュール。どれも三層構造です。

1. **画面で見ているもの** —— 記号の早見表。各項目は辞典の該当項目に直接リンクします。
2. **それらがどう繋がるか** —— 下にある考え方。パネルの裏に畳んであり、開いても無視しても構いません。
3. **どこから来たか** —— 実際のテキスト。年代、著者、論争付きです。

| モジュール | テーマ | 重要性 |
| :--- | :--- | :--- |
| **01** | **[道教のコード](./taoism)** | 錬丹術、お札、そして「気」のシステム。 |
| **02** | **[三界観](./three-realms)** | 天界、人間界、そして冥界（鍾馗の管轄）。 |
| **03** | **[輪廻と因果](./karma)** | なぜ東洋の物語において、死は終わりではないのか。 |
| **04** | **[山海の異獣](./beasts)** | 『山海経』から現代のボスデザインまで。 |
