# 三界観：天庭・人間、そして地下の役所

鍾馗は「冥界の最高法官」です。ではなぜ、ゲームの中の彼は机の後ろで裁かず、自ら剣を持って鬼を追い回しているのでしょうか。

なぜゲームの死後の世界には事務手続きがあるのでしょうか——渡る橋、裁かれる案件、並ぶ順番。

そして、一万年生きている神が、なぜ**左遷**されるのでしょうか。

これらはデザイナーの発明ではありません。宇宙がどう運営されるかについての、非常に古くて具体的な考え方から来ています。

このページは三層構造です。**第一層**は、画面で実際に見ているもの。**第二層**は、それらを一つの動く模型として繋ぎます。**第三層**は、その模型がどこから来たかを示します。各トピックの下には折りたたみパネルがあります——読みたいものだけ開いてください。

## 第二層 · それらはどう繋がるのか

### 1. 三界は三つの世界ではなく、三層の管轄である

上に天庭、中に人間界、下に冥界。アートの違う三つのマップだと読んでしまいがちです。

そうではありません。三界は**重なり合った三層の管轄で、法が異なり、しかも相互に往来が絶えません**。物は上へ行き（祈り、上奏、引き上げられた凡人）、下へも行きます（勅令、左遷された神、罪人）。東洋神話のほとんどすべての物語は、「越えるべきでない境界を何かが越えた」ところから始まります。

だからこそ「世界の均衡が崩れた」がこれほど多い前提になるのです。不均衡は神秘ではなく、**行政の問題**です。

::: details 開く：なぜ人間界が一番面白いのか

天庭が秩序、冥界が審判だとすれば、人間界は**両方から手を伸ばされ、どちらも完全には握れていない中間地帯**です。

プレイヤーがそこに住んでいるのも偶然ではありません。ゲームには「規則を破れる空間」が必要です。天庭も冥界も、規則がすでに機能している場所なのです。
:::

::: details 開く：この考えの出典

中国の初期信仰は死者を**泰山**の下に置き、「泰山府君」という神が司るとしました。漢代の墓券にはすでに冥界の官僚制——名簿と役人——が現れます。

仏教は自前の宇宙観（地獄、輪廻、閻魔）を携えて入ってきましたが、土着の体系を置き換えたのではなく、**統合**されました。結果は混血です——インドの裁判官が、中国の役所に座っている。
:::

### 2. 天庭は政府であり、楽園ではない

東洋の宇宙観を理解するうえで最も役に立つ一点であり、西洋のプレイヤーが最も誤解する点です。

天庭には部署があり、監察があり、位階があり、俸禄があり、煩雑な礼があります。神々には**職位**があります。減俸され、左遷され、流刑にされ、異動させられます。上司がいて、書類を書きます。

最も際立つ特徴は、**意図的に退屈**であることです。秩序は天庭の副産物ではありません。秩序こそが天庭の目的です。

::: details 開く：なぜ「退屈」が設計目標なのか

西洋の天国はしばしば「完成」として描かれます——努力の終わり。東洋の天庭は**動いている組織**として描かれるので、組織の欠点をすべて備えます。派閥、えこひいき、腐敗、サボり。

これが孫悟空の物語を成立させます。彼が反抗したのは「善」ではありません。**人事**です。彼の罪は、自分に見合わない役職を拒んだことです。この笑いが効くのは、読者がその職場を知っているからです。
:::

::: details 開く：この考えの出典

『西遊記』（16世紀）は、玉帝の朝廷が実際に機能する官僚制であるという民間のイメージを定着させました——天馬を管理する役所、管理者のいる蟠桃園、失敗すれば異動になる神々。

しかしその官僚的な感性はずっと古いものです。帝政中国は科挙と任命で動いており、その宇宙観は、文官制度を建てたのと同じ想像力で建てられました。
:::

### 3. 冥界の恐怖は暗闇ではなく、正確さにある

ゲームの冥界に入れば、おどろおどろしさを予想します。炎、叫び、苦痛。

中国の冥界は、まったく別のチャンネルで人を落ち着かなくさせます。静かで、手続き的で、そして——最悪なことに——**公正**です。帳簿があります。帳簿は間違っていません。あなたについての記録は正確で、自分で「あれは数えない」と納得させてきた部分まで含んでいます。

だからこそ「判官」は魅力的で、鍾馗は千年生き延びました。提示されるファンタジーは権力ではありません。**書類を本当に読んでくれる法廷**です。

::: details 開く：なぜ怪物より書記官のほうが怖いのか

怪物は戦えます。正しい書類を持った書記官には、戦えません。

これが多くの志怪小説の下にあるエンジンです。恐怖は体制が残酷なことではなく、体制が**正しい**ことであり、あなたに反論の余地がないことです。主人公に残された手は、記録より正直になるか、記録の誤りを一つ見つけるかだけです。
:::

::: details 開く：この考えの出典

『太平広記』（10世紀）は宋代に編まれた唐代志怪の総集で、冥界裁判の話で溢れています。平凡な人が死に、法廷に連れて行かれ、自分の名簿を見せられ、忘れていた細部に気づく。

『聊齋志異』（18世紀）は後に、その地方版を一つのジャンルにしました——城隍と判官が、小さくて人間的な案件を裁きます。
:::

### 4. 死は手続きであり、壁ではない

西洋の枠組みでは、死は物語の終わりか、別の物語の始まりです。東洋の枠組みでは、死は**過程の中の一工程**です——段階があり、関所があり、担当者がいます。

橋があります。列があります。書記官がいます。出口には一杯のスープがあります。

これはゲームデザインに、見落としやすい直接の帰結をもたらします。**死が手続きである世界では、死者は助けられ、袖の下を使われ、訴えられ、救い出される**。死は「失敗状態」から「冒険できる場所」に変わります。

::: details 開く：だから中国のゲームは人物を殺しても話を続けられる

死が壁なら、主人公を殺せば物語は終わります。

死が手続きなら、主人公を殺すことは**物語を別の場所へ移す**だけです。主人公は冥界と交渉し、脱獄し、送り返され、手続きそのものの誤りを発見できます。物語は境界を止まらずに**通り抜けて**進みます。

だからこそ、こうした物語の「復活」はチートに見えません。それは禁じられていたのではなく、単に高価だったのです。
:::

::: details 開く：この考えの出典

十王（十殿閻王）の体系化は唐から宋へ進み、『仏説十王経』などのテキストに書き表されました。

各殿が審理の一段階を担い、それぞれに主審と刑罰があります。これは**建築として描かれた裁判制度**です——そして、これらのゲームの冥界がしばしば、たまたま地下にあるオフィス街のように見える理由でもあります。
:::

### 5. 境界を越えることが、ほとんどすべての物語のエンジンである

最初の四つを並べれば、パターンが見えてきます。

東洋神話は「英雄が力を欲しがる」「悪役が破壊を欲しがる」から筋を生みません。**境界が越えられる**ことから筋を生みます。凡人が仙薬を盗み、僧の弟子が蟠桃を盗み、鬼が名簿から逃げ、神が受け入れない役職へ異動させられ、妖が身分を超えて修行する。

三界は安定するために存在します。物語は、それが不安定になったから存在します。だから結末はほとんど「悪人を殺す」ではなく、<strong>「世界を動く状態に戻す」</strong>なのです。

### このページの要旨

**東洋神話は、神がどれほど強いかの話ではありません。秩序がどう回っているか、そして壊れたとき誰が直すかの話です。**

だからこそ、これらの物語では鍾馗、判官、城隍が、天庭で一番強い者より重要なのです。彼らは最も力のある者ではなく、**システムを維持する者**です。

そして鍾馗が机の後ろで裁かず、自ら鬼を追う理由でもあります。机のほうは正常に動いている。別のどこかが壊れているのです。

## 第三層 · これらはどこから来たのか

| 概念 | 鍵となるテキスト | 時代 | 何をもたらしたか |
| :--- | :--- | :--- | :--- |
| 魂は泰山へ帰る | 漢代の墓券；泰山府君信仰 | 漢 | 「冥界は統治されている」という土着の観念 |
| 地獄と輪廻 | 仏典；『仏説十王経』 | 唐〜宋 | 閻魔と十殿 |
| 冥界裁判の文学化 | 『太平広記』 | 宋（唐伝奇） | 名簿、法廷、忘れられた細部 |
| 天庭という職場 | 『西遊記』 | 明 | 位階、昇進、左遷、蟠桃泥棒 |
| 地方の神が小事件を裁く | 『聊齋志異』 | 清 | 城隍と判官の人間的な事件簿 |

この層が、このサイトと百科事典の境界線です。中国の宇宙観を語り切るつもりはありません——それ自身の内部で一致しておらず、その不一致こそが面白いのです。

伝えたいのはただ一つ。ゲームで出会う一つひとつの「設定」の裏には、実際のテキストがあり、年代があり、著者がいて、論争がある。デザイナーは作ったのではなく、**読んだ**のです。
