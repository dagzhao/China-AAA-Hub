# 文化 101

中国の AAA ゲームは神話を借りているだけではありません——神話の上で動いています。**東洋の論理**を読むために、下の四つのモジュールを順にどうぞ。

どのモジュールも同じ構造です。**画面で見ているもの**、**それらがどう繋がるか**、**どこから来たか**。深い部分はパネルの裏に畳んであるので、二分で流し読みも、二十分かけて読み込むこともできます。

### 🎓 モジュール

| モジュール | テーマ | 重要性 |
| :--- | :--- | :--- |
| **01** | **[道教のコード](./taoism)** | 陰陽、五行、気、符。なぜこのゲームの戦闘が形而上学なのか。 |
| **02** | **[三界観](./three-realms)** | 天庭・人間界・冥界は三層の管轄——なぜこの宇宙観が組織図なのか。 |
| **03** | **[輪廻と因果](./karma)** | 死はチェックポイント、帳簿は自ら帳尻を合わせる。なぜ誰も「勝って終わり」にできないのか。 |
| **04** | **[山海の異獣](./beasts)** | すべてのボスの背後にある共有図鑑。なぜ中国の怪物は「考証」なのか。 |
