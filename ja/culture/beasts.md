# 山海の異獣：なぜ中国の怪物は「発明」ではなく「考証」なのか

西洋ファンタジーのゲームを遊ぶと、たいてい各モンスターの裏にあるデザイン会議を言い当てられます。これは竜の変種、あれはひねりを加えたゾンビ、ボスが蜘蛛なのは蜘蛛がそのサイズで映えるから。

中国のゲームを遊ぶと、感触が違います。ボスたちは**引用されている**ように感じられます。

なぜ、体がまったくなく顔だけの怪物がいるのでしょうか。

なぜこの文化で最も有名な瑞獣の一つは、「統治がうまくいっているとき」にしか現れないのでしょうか。

そして、なぜ設定資料集は、二千年前にはすでに古かった本を繰り返し参照するのでしょうか。

このページは三層構造です。**第一層**は、画面で実際に見ているもの。**第二層**は、それらを一つの動く模型として繋ぎます。**第三層**は、その模型がどこから来たかを示します。各トピックの下には折りたたみパネルがあります——読みたいものだけ開いてください。

## 第二層 · それらはどう繋がるのか

### 1. 山海経は地理誌であり、神話集ではない

『山海経』について最も役に立つ認識は、**それがどの種類の本か**です。

経典でも叙事詩でもありません。**地理誌**です——想像された世界の踏査記録で、地域ごとに進み、そこに何がいるか、どんな姿か、何を食べるか、食べたらどうなるかを記します。一部は実在と分かる動物。一部は頭が二つある山です。

この体裁が、中国のモンスターデザインを「考証」に見せている理由です。デザイナーが生き物を必要とするとき、ムードボードから発明するのではなく、**踏査記録から引く**のです。そしてその記録には索引があり、版ごとの異同があり、二千年にわたる解釈の論争があります。

::: details 開く：「地理誌」が含意して「神話集」が含意しないもの

神話集は起源と神々を説明します。地理誌は**位置を割り当てます**。

だから東洋の生き物には住所が付きます。九尾の狐は東にいる。饕餮は青銅器の上にいる。麒麟は治世に現れる。すべての生き物がどこかにいるということは、すべての生き物が**見つけられる**ということであり、これはオープンワールドのゲームがまさに必要とするものです。
:::

::: details 開く：この考えの出典

『山海経』は層をなして成立しました。古い山経の核があり、戦国期に拡張され、漢代に安定して十八巻となりました。

当時それは虚構として読まれたのではなく、**参考図書**として扱われました。だからこそ語り直されるのではなく、注され、校され、論じられ続けたのです。
:::

### 2. 中国の怪物は修行して成る。生まれつきではない

これが中国の怪物誌と西洋のそれの最大の違いであり、物語の中で怪物が何になりうるかを決めます。

西洋の怪物には通常「本性」があります。悪魔は悪魔であり、その種がすることをします。中国の「妖」は**結果**です。獣でも草木でも器物でも、十分に長く修行したもの——多くの場合、山に数百年いたもの——が霊智と姿を得ます。

つまり妖に先天的な立場はありません。どう修行したか、そして人がどう扱ったかが、それを決めます。

::: details 開く：だから中国の敵役には前史がある

怪物の本性が固定なら、前史は飾りです。本性が**過程の結果**なら、前史は仕組みそのものです。

だから中国のゲームの敵役は、長く、同情的に描かれることが多いのです。デザイナーは邪悪な生き物を柔らげているのではなく、**その修行を見せている**のです——どうやってここに至ったか、何から変わったか、誰のせいで。
:::

::: details 開く：この考えの出典

「修行が本類を変える」という観念は、仏教と同じくらい道家の伝統から来ています——内丹については[道教のコード](/ja/culture/taoism)を参照。

最も影響力のある文学形態は『聊齋志異』（18世紀）です。そこでは狐は怪物ではなく人物です——誇り高く、狭量で、寛大で、執念深く、そして道徳的に読み取れます。この本の主張はつまり、**妖の倫理は獲得されるものだ**ということです。
:::

### 3. 神獣の機能は瑞兆であり、戦闘力ではない

西洋の竜は力のファンタジーです。その機能は障害物であり、報酬です。

麒麟はそれをしません。麒麟は**世がよく治まったときに現れます**。しかも故意に何も傷つけない——生きた草を踏まずに歩くといわれます。強くはありません。**意味がある**のです。

これはまったく別の職務記述書であり、西洋のプレイヤーが戸惑う点を説明します。なぜ東洋の神獣の多くは戦わないのか。彼らは戦われるためにいるのではなく、**信号**として——世界が自分の状態を告げるためにいるのです。

::: details 開く：なぜ数値より瑞兆のほうが世界観に向くのか

世界の状態を示す生き物は、どこにでも、どの規模でも、戦闘を添えずに置けます。

村に麒麟を一頭置けば、その地域が平和だと伝わります——低コストで、台詞もクエストマーカーも要りません。門に饕餮を刻めば、その内側の者が何を恐れているかが伝わります。情報コスト比が極めて高いのです。
:::

::: details 開く：この考えの出典

瑞兆の伝統は『尚書』と歴代の上奏制度の双方を貫いています。異獣や異変、天文現象が記録されたのは、それらが**読まれる**ものだったからです——統治の質についての報告として。

麒麟の最も有名な登場は「西狩獲麟」です。魯の哀公十四年の狩りで麒麟が捕らえられ、孔子はそこで筆を絶ち、『春秋』はここで終わります。同じ獣が、場面によって正反対の役割を担います——そのとき何を語る必要があったかによって。
:::

### 4. 図鑑そのものがキャラクターになりうる

白澤は、あらゆる精霊の真名・姿・対処法を知っています。

これが何なのかに注目してください。**索引が人格化されている**のです。白澤は戦力ではありません。顔のついたデータベースであり、しかもその名を冠した書物があります——『白澤図』、精霊を見分けて対処するための手引きです。

鍾馗がこれに跨る画があります。裁判官が、索引を連れている。

::: details 開く：なぜ「図鑑をキャラクターにする」が本物の設計手なのか

索引がキャラクターになれば、場面に置けます。

これらのゲームはまさにそうしています。「喋る導き手」——名前を教えてくれる生き物。これはゲームプレイ上の便宜であり、同時に非常に古い文学装置です。図鑑は虚構の外にあるメニューではなく、虚構の**内側**にあり、しかも意見を持っています。
:::

::: details 開く：この考えの出典

『白澤図』は中世において実用的な精霊の手引きとして流布しました——何がいて、どう扱うかの一覧です。

これは『山海経』を生んだのと同じ本能です。不可知な世界に直面した文化が、**それの目録を書く**という反応です。
:::

### 5. デザイナーは発明せず、引用する

最初の四つを並べれば、中国のモンスターデザイン特有の質感が出てきます。

生き物は住所付きの踏査記録から来ます。その本性は割り当てられたものではなく獲得されたものです。非戦闘の者たちは障害物ではなく瑞兆です。そしてこの文化にはすでに神話化された索引があります。

だからゲームがボスを目の前に置くとき、その設計上の手はたいてい**翻訳であり、発明ではありません**。どの項目か、どの版か、どの細部が長く論争されてきたか——そしてそれが動くとどんな姿になるか。

### このページの要旨

**山海経の世界では、怪物は敵ではありません。世界の一部です。戦うのは、それが道を塞いでいるからであって、邪悪だからではありません。**

だからこれほど多くの中式モンスターデザインに、拭えない**出典感**があるのです。それはスタイルの選択ではありません。原資料の体裁そのものが、二千年を経て、たまたまそういう本を必要としていた媒体へ運ばれてきたものです。

## 第三層 · これらはどこから来たのか

| 概念 | 鍵となるテキスト | 時代 | 何をもたらしたか |
| :--- | :--- | :--- | :--- |
| 想像された世界の踏査 | 『山海経』 | 戦国〜漢 | 住所付きの共有された怪物図鑑 |
| 最初の体系的な注 | 郭璞『山海経注』 | 東晋 | 怪物が語り直されず、説明された |
| 万物に名を与え分類する | 『爾雅』 | 戦国〜漢 | 「名を正しくする」伝統 |
| 精霊の扱い方 | 『白澤図』 | 中世 | 索引という使える道具 |
| 倫理を持つ獣 | 『聊齋志異』 | 清 | 妖が怪物ではなく道徳的な人物になる |

この層が、このサイトと百科事典の境界線です。『山海経』を語り切るつもりはありません——三百余りの項目があり、人々は二千年にわたって論じてきました。

伝えたいのはただ一つ。ゲームで出会う一つひとつの「設定」の裏には、実際のテキストがあり、年代があり、著者がいて、論争がある。デザイナーは作ったのではなく、**読んだ**のです。
