# 『明末：ウツロノハネ』全エンディング・真エンディング攻略

『明末：ウツロノハネ（WUCHANG: Fallen Feathers、中国語名：明末：淵虚之羽）』には **4つのエンディング** があります。うち2つは見逃しやすく、「どれが真エンドか」は攻略サイトによっても見解が分かれます。この記事では、各エンディングの正確な条件、後戻りできないポイント、1周で全部見るためのセーブバックアップ方法をまとめます。

## 早見表

| エンディング | 種類 | 主な条件 |
| :--- | :--- | :--- |
| **僰人の継承者（Successor of the Bo）** | 隠し / 早期終了 | 紅衣女のクエストを完了し、丹青苑（Annalum）で説話人を拒否 |
| **薬を育む者（Jarful of Medicine / 飼薬之人）** | バッド / デフォルト | **莹羽のたがね**を玄陽子に渡し、最後に「再入輪廻」を選ぶ |
| **まるで夢のよう（Dream's Sweet Deceit / 如真似夢）** | 隠し夢エンド（真エンドとする攻略も） | 五つの羽鑿を集め、双環を完成、**輪廻の環・再生**を合成、「進入幻夢之境」を選ぶ |
| **定めなき命（Bound by Fate's Threads / 命裏無時）** | グッド / 叙事的真エンド | 羽鑿を渡さず、方瑤・何有哉を生かし、最終選択時に**再生の環を所持していない**状態で「進入真實之境」を選ぶ |

## 五つの羽鑿（重要）

「まるで夢のよう」を狙うなら、**五つの羽鑿**を集めます。玄陽子に渡してはいけないのは **莹羽のたがね** です。渡すと一本欠けてしまいます。

| 羽鑿 | 入手先 | 効果 |
| :--- | :--- | :--- |
| 初期の羽鑿 | 開始時から所持 | 死亡後に直近の入夢点へ戻り強化 |
| **莹羽のたがね** | 第二章ボス・**完璧なる花嫁 方霊** | 神祠で「先神之言」を解放 |
| **金羽のたがね** | 第三章ボス・**大西王 張献忠** | 羽露瓶の回復量を最大に |
| **赤羽のたがね** | 第四章ボス・**真龍天子 朱由検** | 武器熟練度を +10 まで強化 |
| **青羽のたがね** | 第五章の隠しボス・**趙雲**（真武山・鳥人の沼・衣冠塚） | 最後の淬羽スロットを解放 |

> 青羽のたがねは趙雲との会話を進め、朱由検撃破後に真武山の鳥人の沼・衣冠塚でイベントを発生させます。

## 1. 隠しエンド：僰人の継承者（Successor of the Bo）

最も早く終われますが、条件を逃すと二度と戻れません。

1. 第三章、**鳥人の沼（Avian Dwelling）** で **紅衣女（Bo Magus / 僰人の巫祝）** に会い、彼女の提案に**同意**します。
2. 第四章、**真武山** の **猛虎（Fierce Tiger）** を倒した後、**丹青苑（Annalum）** に到着します。
3. **説話人** に「先へ進むか」と聞かれたら、**拒否**します。「Continue Forward」を選ばないでください。
4. **紅衣女（僰人の巫祝）** を倒します。

ゲームは早期に終了し、僰人の都には行けません。専用トロフィー **「僰人の継承者」** があります。

> **後戻り不可：** 丹青苑の説話人イベント。先へ進む前に、真武山とWorship's Riseの探索・NPCクエストを済ませてください。

## 2. 薬を育む者（Jarful of Medicine / 飼薬之人）

輪廻の環クエストを完了しない場合の既定ルートです。

1. 第四章、**普元寺** から **燃燈洞（燃燈洞窟）** へ向かう途中で **玄陽子** に会います。
2. **莹羽のたがね（Jade Feather Chisel / 羽鑿）** を求められたら渡します。
3. **何有哉** と **方瑤** のクエストを完了せず、再生の環を合成できなくします。
4. 最終ボスを倒します。
5. 最後の門で **「再入輪廻」** を選びます。

多くの攻略で「バッドエンド」と呼ばれます。専用トロフィーは **「薬を育む者」** です。

## 3. まるで夢のよう（Dream's Sweet Deceit / 如真似夢）

最も条件が多く、日本語攻略では**真エンディング**とされることが多い隠し夢エンドです。

1. **五つの羽鑿を集めます**（上の表を参照）。
2. **莹羽のたがねを保持します。** 玄陽子に求められたら **「沈黙」** を選び、渡さないでください。
3. **何有哉** と **方瑤** のクエストを完了し、**二人生存** させます。
   - 方瑤のクエストには **Hillswatch（秽柳灘）** の **蜀錦のスカーフ（Shu Silk Scarf）** が必要で、**Cloudspire（雲頂城）** の彼女の家の前で怪物を倒す必要があります。
4. **輪廻の環・因** と **輪廻の環・果** を両方入手します（第四章・普元寺）。
5. **古都深處（僰人の古都）** の3つ目の謎解き門で、あえて**誤答「再入輪廻」** を選びます（正解「大夢已寤」ではありません）。
6. **蜀神居所** で **執念・心魔（Demon of Obsession）** を倒します。
7. 同じ **蜀神居所** の祭壇で、因と果を合成して **輪廻の環・再生** を作ります。
8. 再生の環を所持したまま、最終ボス **玄陽子** を倒します。
9. 門で **「進入幻夢之境」** を選びます。姉妹で船に乗る演出が入ります。

専用トロフィーは **「まるで夢のよう」** です。

## 4. 定めなき命（Bound by Fate's Threads / 命裏無時）

GameSpotなどの英語攻略は、こちらを**真エンディング**と呼びます。叙事上も「真実の境」へ進み、左腕の羽が消える演出があります。

1. 「まるで夢のよう」と同じ手順で、最終ボス直前まで進みます。**羽鑿は4つでも5つでも構いません**（青羽のたがねは必須ではありません）。
2. 方瑤と何有哉を**生存**させた状態で、最終ボス前まで進みます。
3. 門に触れる前に、**輪廻の環・再生を所持していない**状態にします。アイテム欄から使用・消費するか、そもそも合成しません。
4. **玄陽子** を倒します。
5. 門で **「進入真實之境」** を選びます。

専用トロフィーは **「定めなき命」** です。

## どれが真エンディング？

**公式は「真エンド」を定義していません。** 4つとも専用トロフィーを持つ正規のエンディングです。見解は2つに分かれます。

- **GameSpot など：** **定めなき命（命裏無時）** を真エンドとする。叙事上「真実の境」へ進み、羽が消えるため。
- **TheGamer、DualShockers、PowerPyx、日本語・中国語攻略：** **まるで夢のよう（如真似夢）** を真エンドとする。5つの羽鑿＋双環＋再生環＋執念・心魔と、解放条件が最も厳しいため。

つまり「叙事の真相」を取るか「解放難度」を取るかで答えが変わります。英語名 **Dream's Sweet Deceit** は直訳すると「甘い偽りの夢」で、こちらも夢の中の結末であることを示唆します。

## 1周で全エンディングを見る

手動セーブのバックアップが定石です。

1. **丹青苑（Annalum）の説話人イベント前**——隠しエンド用。
2. **燃燈洞の玄陽子イベント前**——莹羽のたがねの選択用。
3. **最終ボス後、門に触れる前**——幻夢／真実の分岐用。

PCのセーブフォルダ：

`C:\Users\[ユーザー名]\AppData\Local\Project_Plague\Saved`

各分岐の前にフォルダごとバックアップし、戻して最終選択をやり直します。コンソールではクラウドセーブ／手動セーブを利用してください。

## FAQ

**1周で4つ全部見られますか？**
手動バックアップがあれば可能です。なければ、莹羽のたがねと再生の環の選択が不可逆なため、最低2周必要です。

**莹羽のたがねを玄陽子に渡すとグッドエンドは無理ですか？**
はい。渡すと **薬を育む者（Jarful of Medicine）** になります。グッドを狙うなら「沈黙」を選んで保持してください。

**まるで夢のようと定めなき命、どちらが真エンドですか？**
攻略サイトによります。GameSpotなどは **定めなき命**、TheGamer/DualShockers/PowerPyxと日本語攻略は **まるで夢のよう** を真エンドと呼ぶことが多いです。どちらも専用トロフィーがあり、両方とも正規のエンディングです。

**DLCは必要ですか？**
不要です。4つとも本編で見られます。
